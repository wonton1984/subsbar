# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; harassment, hate speech, personal
attacks, and publishing others' private information are unacceptable.
Maintainers may remove comments, issues, or PRs that violate this code and may
block repeat offenders. Reports go to the maintainers via GitHub Security
Advisories or direct contact, and are handled confidentially.
